# UI component description template

最终整理时使用此模板。删除说明文字、示例行和不适用的状态；未知但不阻塞交付的值写成 `待确认`，不要留空或发明数值。只保留有证据或需要明确追踪的内容。

建议路径：`docs/<project>/desc/<component>.md`。路径只是默认建议，始终以用户明确确认的位置为准。
