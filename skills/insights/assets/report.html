计算口径与缺口

Used = Input − Cached input + Output；缓存命中率 = 缓存输入总数 ÷ 对应的已知输入总数。Input 包含缓存；Output 包含推理，不能再加一次。缺失缓存字段不会当成 0。

只统计采集到的主会话，排除子代理。按快照时间归属日期，累计快照取差值；重复快照不重复计入，未知基线和计数回退会留下缺口。这不是完整账单或效率评分。

无可计算记录显示为缺口；长期间按相邻日期合并，缓存率按合并后的 token 数计算。
